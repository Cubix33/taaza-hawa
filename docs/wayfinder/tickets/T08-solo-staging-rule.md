# T08 · Solo staging rule (grilling, HITL)

Label: `wayfinder:grilling` · Open, frontier · Needs the user

## Question

Which of these does the user accept for the 3-minute film?

1. **Natural user only.** The entrant is the real user (resident, student, commuter, site owner). Strongest honesty, narrowest idea space.
2. **Two roles on two devices, labelled.** The entrant triggers as one role and acknowledges as another (Suraksha did exactly this). Real data, real system, staged people.
3. **Simulated physical layer, labelled.** A sensor or device is simulated when hardware is essential (the user said this is acceptable).

## Chair's working assumption

Options 2 and 3 are allowed with on-screen labels; option 1 is preferred when available. The idea search in [T09](T09-shortlist-and-council.md) scores candidates higher when they need less staging.

## Resolution

_Open. The user confirms or corrects the assumption._
